# Dweer Island KDE

Графитовый рабочий стол для **Debian 13 · KDE Plasma 6.3 · Wayland**.
Одна установка: верхняя панель с часами в чёрном островке, прозрачные
промежутки, нижний док, цветные значки приложений и виджеты без рамок.

**Обои остаются твоими.** Установщик не меняет фон и не скачивает обои.
В репозитории нет личных фотографий, скриншотов рабочего стола или настроек аккаунтов.

## Установить

Запусти в терминале **от своего обычного пользователя**, без `sudo` перед
скриптом. Пароль администратора понадобится только для установки пакетов Debian.

```bash
curl -fL https://raw.githubusercontent.com/saparbejbarys8-droid/dweer-island-kde/v1.0.0/bootstrap.sh -o /tmp/dweer-island-install.sh && bash /tmp/dweer-island-install.sh
```

Если `curl` отсутствует, сначала установи его: `sudo apt install curl`.
Если `sudo` отсутствует, установка пакетов запросит пароль `root` через `su`.

Можно через Git:

```bash
git clone https://github.com/saparbejbarys8-droid/dweer-island-kde.git
cd dweer-island-kde
./install.sh
```

На чистом Debian с KDE оформление применится сразу. На Debian без графической
оболочки скрипт установит KDE и SDDM, затем подготовит применение при первом
входе: перезагрузи компьютер и выбери **Plasma (Wayland)**. Существующую
графическую сессию установщик сам не завершает.

## Что получится

- Верхняя панель: меню Debian слева, часы точно по центру в округлом чёрном
  островке, системные значки справа. Между блоками видны текущие обои.
- Плавающий док снизу с автоматическим скрытием при перекрытии окном.
  Файловый менеджер, Kitty, Firefox ESR, настройки и Discover устанавливаются
  из Debian. Уже установленные Chrome, Spotify и Telegram также закрепляются;
  их установку и аккаунты скрипт не настраивает.
- «Загрузки веером»: последние восемь файлов, открытие файла или папки.
  Путь берётся из XDG, включая локализованную папку «Загрузки».
- Тёмное оформление Kvantum, заголовки окон с цветными кнопками слева,
  обычные цветные иконки Breeze. Темы отдельных приложений могут задаваться
  самими приложениями.
- Часы, фоторамка со скруглением и заполнением всей площади, управление
  музыкой и сетью. У виджетов убраны фоновые рамки. **Фото выбираешь сам**:
  открой настройки фоторамки и укажи папку с картинками.
- Масштаб 90% на подключённых дисплеях Wayland. Разрешение и частота обновления
  не меняются. Для сохранения своего масштаба передай `--scale=keep`.

Это настройка KDE, отдельный Waybar не требуется. Прежние панели заменяются;
файлы на рабочем столе, его фон и посторонние виджеты сохраняются.

## Параметры

```bash
./install.sh --scale=keep
./install.sh --scale=0.95
./install.sh --photo-dir="$HOME/Pictures/My Photos"
```

`--no-apt` пропускает установку системных пакетов, если зависимости уже есть.
`--prepare-only` устанавливает только ресурсы: не меняет текущий вид рабочего
стола и не добавляет автоматическое применение при входе.

После установки доступны пункты меню **«Применить Dweer Island KDE»** и
**«Вернуть прежний KDE»**. Повторное применение пересоздаёт панели и размещает
виджеты заново, поэтому используй его, когда хочешь вернуть исходную раскладку.

## Откат

В меню приложений выбери **«Вернуть прежний KDE»** или выполни:

```bash
~/.local/bin/dweer-island-kde restore
```

Восстановятся настройки до первой установки: панели, оформление, виджеты и
масштаб экрана. Для отката только последнего применения:

```bash
~/.local/bin/dweer-island-kde restore --latest
```

Копии находятся в `~/.local/state/dweer-island-kde/backups/`. Откат оставляет
пакеты Debian и локальные ресурсы темы установленными; они не применяются.
Пользовательские приложения остаются открытыми при перезапуске Plasma Shell.

## Совместимость и проверка

Поддерживается Debian 13 с Plasma **6.3.x**. Для Debian 12 / Plasma 5 и других
версий Plasma установщик остановится до изменения оформления.
Системные пакеты берутся из настроенных официальных репозиториев Debian:
[KDE Plasma](https://packages.debian.org/trixie/kde-plasma-desktop),
[Kvantum](https://packages.debian.org/trixie/qt-style-kvantum).

Локальная интеграционная проверка запускает отдельную сессию D-Bus и
виртуальный KWin с пустым домашним каталогом. Она проверяет установку,
повторное применение, сохранение обоев, откат масштаба и применение при входе:

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
timeout 240s ./tests/run-session.sh
```

Проверка устанавливает ресурсы только в свой временный каталог `/tmp`.
Для неё нужны зависимости из установщика.
