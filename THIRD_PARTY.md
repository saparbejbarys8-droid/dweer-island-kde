# Upstream components

The installer builds local variants from Debian's installed packages. Generated
KDE source trees and Kvantum assets are not committed to this repository.
Original copyright notices remain in generated QML and JavaScript files.

- KDE Plasma panel (`org.kde.panel`): Plasma Workspace, GPL-2.0-or-later.
  Source: https://invent.kde.org/plasma/plasma-workspace
- Media Frame: KDE Plasma Addons, GPL-2.0-or-later.
  Source: https://invent.kde.org/plasma/kdeplasma-addons
- Media Controller: KDE Plasma Workspace; see the source files' SPDX notices.
- Network Management widget: KDE Plasma Network Management; see its SPDX notices.
  Source: https://invent.kde.org/plasma/plasma-nm
- Breeze desktop theme: KDE Plasma Framework, LGPL (see the installed package's
  copyright file for the per-file license).
  Source: https://invent.kde.org/plasma/libplasma
- KvMojave color palette and Qt style: Kvantum, GPL-3.0-or-later.
  Source: https://github.com/tsujan/Kvantum
- Breeze application icons and the Debian menu emblem are provided by Debian
  packages. This repository does not redistribute them.
